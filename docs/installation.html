Installation

Multiple ways to install and run H@H-rs on your system.

📋 Prerequisites

Before installing H@H-rs, you'll need:

  • A registered H@H client from the E-Hentai forums
  • Your Client ID and Client Key
  • Port forwarding configured on your router (default: 8080)
  • Sufficient disk space for caching (configurable, default: 100GB)

🐳 Docker Installation (Recommended)

1

Clone the Repository

git clone https://github.com/atristar3/h-at-h-rs.git
cd h-at-h-rs
2

Configure Environment

cp .env.example .env

# Edit .env with your credentials
nano .env

Set at minimum: HAH_CLIENT_ID and HAH_CLIENT_KEY

3

Create Data Directories

mkdir -p data/cache data/temp data/db
4

Start the Container

docker-compose up -d

# View logs
docker-compose logs -f

Alternative: Direct Docker Run

docker run -d \
  --name hah-rs \
  --restart unless-stopped \
  -p 8080:8080 \
  -v $(pwd)/cache:/app/cache \
  -v $(pwd)/db:/app/db \
  -e HAH_CLIENT_ID=your_client_id \
  -e HAH_CLIENT_KEY=your_client_key \
  -e HAH_CACHE_SIZE_GB=100 \
  ghcr.io/atristar3/h-at-h-rs:latest

# Download for your platform (example: Linux x86_64)
curl -LO https://github.com/atristar3/h-at-h-rs/releases/latest/download/h-at-h-rs-linux-amd64.tar.gz

# Extract
tar xzf h-at-h-rs-linux-amd64.tar.gz

# Make executable (Linux/macOS)
chmod +x h-at-h-rs

# Run
./h-at-h-rs --client-id YOUR_ID --client-key YOUR_KEY

🔧 Build from Source

Requires Rust 1.75+

# Install Rust (if not already installed)
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Clone repository
git clone https://github.com/atristar3/h-at-h-rs.git
cd h-at-h-rs

# Build release binary
cargo build --release

# Binary is at ./target/release/h-at-h-rs
./target/release/h-at-h-rs --help

✅ Verify Installation

After starting the client, verify it's working:

# Check health endpoint
curl http://localhost:8080/api/health

# Check client status
curl http://localhost:8080/api/status

You should see JSON responses indicating the client is running and connected to the H@H network.
