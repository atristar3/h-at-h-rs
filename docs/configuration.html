Configuration

All configuration options for H@H-rs via environment variables or CLI flags.

Quick Navigation

Required → Network & Storage → Bandwidth → Features → ExHentai → Logging →

* Required Settings

These settings are mandatory for the client to connect to the H@H network.

Environment Variable CLI Flag Description
HAH_CLIENT_ID --client-id Your H@H client ID (numeric)
HAH_CLIENT_KEY --client-key Your H@H client key (alphanumeric)

⚠️ Security Notice

Never commit your credentials to version control. Use .env files (gitignored) or Docker secrets for production deployments.

🌐 Network & Storage

Environment Variable Default Description
HAH_PORT 8080 Port to listen on for file requests
HAH_BIND_ADDRESS 0.0.0.0 Address to bind the server to
HAH_CACHE_DIR ./cache Directory for cached files
HAH_CACHE_SIZE_GB 100 Maximum cache size in gigabytes
HAH_MIN_FREE_SPACE_GB 5 Minimum disk space to keep free
HAH_REQUEST_TIMEOUT 30 HTTP request timeout in seconds

📊 Bandwidth Throttling

Control upload/download speeds and bandwidth quotas.

Environment Variable Default Description
HAH_MAX_UPLOAD_SPEED -1 Maximum upload speed in KB/s (-1 = unlimited)
HAH_MAX_DOWNLOAD_SPEED -1 Maximum download speed in KB/s (-1 = unlimited)
HAH_MAX_HOURLY_BANDWIDTH -1 Maximum hourly bandwidth in MB (-1 = unlimited)

Example: Limit to 10 Mbps upload

HAH_MAX_UPLOAD_SPEED=1250  # 1250 KB/s ≈ 10 Mbps

⚙️ Features

Environment Variable Default Description
HAH_STATIC_RANGES false Enable static range proactive caching
HAH_PROXY_MODE false Forward requests for uncached files
HAH_GALLERY_DOWNLOAD true Enable gallery download API
HAH_DOWNLOAD_WORKERS 4 Number of concurrent download workers
HAH_ENABLE_METRICS true Enable metrics collection
HAH_TUI false Enable terminal UI dashboard

🔐 ExHentai Access

To access ExHentai content, provide your browser cookies.

Environment Variable Cookie Name Required
HAH_EXHENTAI_MEMBER_ID ipb_member_id Yes
HAH_EXHENTAI_PASS_HASH ipb_pass_hash Yes
HAH_EXHENTAI_IGNEOUS igneous Optional

How to get your cookies:

  1. Log in to exhentai.org in your browser
  2. Open Developer Tools (F12) → Application → Cookies
  3. Copy the values for ipb_member_id, ipb_pass_hash, and optionally igneous

📝 Logging

Environment Variable Default Description
HAH_LOG_LEVEL info Log level: trace, debug, info, warn, error
HAH_LOG_JSON false Output logs in JSON format
RUST_LOG — Standard Rust log filter (overrides HAH_LOG_LEVEL)

📄 Example .env File 

# Required
HAH_CLIENT_ID=123456
HAH_CLIENT_KEY=abcdef1234567890

# Network
HAH_PORT=8080
HAH_CACHE_DIR=/data/hah/cache
HAH_CACHE_SIZE_GB=200

# Bandwidth (optional)
HAH_MAX_UPLOAD_SPEED=2500    # ~20 Mbps
HAH_MAX_HOURLY_BANDWIDTH=-1  # Unlimited

# Features
HAH_STATIC_RANGES=true
HAH_GALLERY_DOWNLOAD=true

# ExHentai (optional)
HAH_EXHENTAI_MEMBER_ID=your_member_id
HAH_EXHENTAI_PASS_HASH=your_pass_hash

# Logging
HAH_LOG_LEVEL=info
