REST API Reference

Complete API documentation for monitoring and controlling H@H-rs.

Base URL

http://localhost:8080

Replace with your server's address and port.

Endpoints

Health & Status → Metrics → Cache → Gallery Downloads → Archive Downloads → Bandwidth →

🖼️ Gallery Downloads

Download galleries page-by-page via web scraping.

POST /api/gallery/download

Queue a gallery for download

Request Body

// By URL
{
  "url": "https://e-hentai.org/g/1234567/abcdef1234/"
}

// By ID and token
{
  "gallery_id": "1234567",
  "gallery_token": "abcdef1234"
}

// With page range
{
  "gallery_id": "1234567",
  "gallery_token": "abcdef1234",
  "start_page": 1,
  "end_page": 50
}

Response

{
  "success": true,
  "data": {
    "gallery_id": "1234567",
    "status": "queued"
  }
}

List all gallery downloads

📦 Archive Downloads

Download complete gallery ZIP archives.

POST /api/archive/download

Queue an archive for download

Request Body

// By URL (original quality)
{
  "url": "https://e-hentai.org/g/1234567/abcdef1234/"
}

// With resolution
{
  "gallery_id": "1234567",
  "gallery_token": "abcdef1234",
  "resolution": "1280"
}

// Available resolutions:
// "org" - Original (highest quality)
// "2400" - 2400px max
// "1600" - 1600px max
// "1280" - 1280px max
// "980" - 980px max
// "780" - 780px max
GET /api/archive/status/{gallery_id}

Get archive download status

Query Parameters

  • resolution - Filter by resolution (optional)
GET /api/archive/file/{gallery_id}

Download completed archive ZIP file

Example

curl -O -J http://localhost:8080/api/archive/file/1234567

⚠️ Error Responses

All endpoints return errors in a consistent format:

{
  "success": false,
  "error": "Error message describing what went wrong"
}

HTTP Status Codes

  • 200 - Success
  • 400 - Bad Request
  • 404 - Not Found
  • 500 - Server Error

Common Errors

  • Gallery not found
  • Invalid gallery URL
  • Download already in progress
  • ExHentai access required

💻 cURL Examples 

# Check health
curl http://localhost:8080/api/health

# Get full status
curl http://localhost:8080/api/status

# Queue gallery by URL
curl -X POST http://localhost:8080/api/gallery/download \
  -H "Content-Type: application/json" \
  -d '{"url": "https://e-hentai.org/g/1234567/abcdef1234/"}'

# Queue archive with resolution
curl -X POST http://localhost:8080/api/archive/download \
  -H "Content-Type: application/json" \
  -d '{"gallery_id": "1234567", "gallery_token": "abcdef1234", "resolution": "1280"}'

# Check download status
curl http://localhost:8080/api/gallery/status/1234567

# Download completed archive
curl -O -J http://localhost:8080/api/archive/file/1234567

# Get metrics
curl http://localhost:8080/api/metrics | jq
