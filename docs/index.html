Hentai@Home Client for Rust

A high-performance, fully-compatible H@H client implementation with Docker support, gallery downloading, and modern infrastructure features.

Get Started → Download

Features

⚡

Full Protocol Support

100% compatible with the official H@H protocol. Server authentication, heartbeat, static ranges, and all server commands.

📥

Gallery Downloads

Download galleries page-by-page or as ZIP archives. Supports multiple resolutions and ExHentai access.

🐳

Docker Ready

Easy deployment with Docker and docker-compose. Multi-arch images for amd64 and arm64 available on GHCR.

🖥️

Terminal UI

Built-in terminal dashboard for real-time monitoring. View stats, downloads, cache info, and logs.

📡

REST API

Full REST API for monitoring and control. Queue downloads, check status, and view metrics programmatically.

🚀

High Performance

Written in Rust for maximum performance. Optimized hash lookups, concurrent downloads, and low memory usage.

Quick Start

🐳 Using Docker 

# Pull the image
docker pull ghcr.io/atristar3/h-at-h-rs:latest

# Run with your credentials
docker run -d \
  --name hah-rs \
  -p 8080:8080 \
  -v ./cache:/app/cache \
  -e HAH_CLIENT_ID=your_id \
  -e HAH_CLIENT_KEY=your_key \
  ghcr.io/atristar3/h-at-h-rs:latest

📦 Using Binary 

# Download latest release
curl -LO https://github.com/atristar3/\
h-at-h-rs/releases/latest/download/\
h-at-h-rs-linux-amd64.tar.gz

# Extract and run
tar xzf h-at-h-rs-linux-amd64.tar.gz
./h-at-h-rs \
  --client-id your_id \
  --client-key your_key
